# ANSYS Maxwell Simulations

This directory documents electromagnetic simulations of the custom magnetron assembly using ANSYS Maxwell.

## Contents

- Native solver projects and model setup
- Geometry, excitation and material definitions
- Mesh and boundary-condition settings
- Original field exports
- Processed results and comparison figures (stored separately)

## Data Integrity

Preserve original solver exports without modification. Document coordinate systems, component definitions and units. Derived data must identify its source files and processing method.

## Known Analysis Issue

A previous post-processing workflow applied an additional factor of 1000 to a parallel-field profile. Corrected results must be traceable to the original exports, and the component definitions must be verified before physical interpretation.

## Status

Model settings, raw-export inventory and FEMM comparison remain to be documented or verified.
