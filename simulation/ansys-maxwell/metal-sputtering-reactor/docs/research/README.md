## Evidence standard

Distinguish clearly between:

- **Measured:** obtained from physical experiments or instruments;
- **Simulated:** produced by a numerical model;
- **Calculated:** derived analytically or through post-processing;
- **Hypothesis:** a proposed explanation or design expectation not yet verified.

Cite external sources for scientific claims. Record model assumptions, boundary conditions, uncertainty and limitations alongside conclusions. A simulation result should not be described as experimentally validated without supporting measurements.
