# References

This directory indexes scientific publications, technical standards and other sources used in the reactor design and analysis.

## Contents

- `bibliography.bib` — BibTeX bibliography entries
- `papers.md` — annotated list of relevant papers and technical references

## Reference practice

For each source, record the complete citation and DOI or stable URL when available. Add a short note explaining which design decision, equation, material property or validation method the source supports.

Prioritise primary research papers, standards, official software documentation and authoritative material-property sources. Verify that a source actually supports the associated claim; do not cite a paper merely because it concerns magnetron sputtering generally.

Respect copyright and redistribution terms. When a paper cannot legally be redistributed, store its citation and link rather than uploading the full text.
