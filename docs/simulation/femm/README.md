# FEMM Simulations

This directory contains FEMM models and supporting files for the reactor's magnetostatic analysis.

## Contents

- Native FEMM models (.FEM)
- Material definitions and magnetic properties
- Model assumptions and boundary conditions
- Field exports used for analysis

## Reproducibility

Record geometry, excitation, material properties, mesh settings and solver assumptions for each model. Keep original exports unchanged and document any post-processing separately.
